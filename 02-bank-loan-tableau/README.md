# Bank Loan Portfolio Analytics (Tableau)

Academic work from *Data Visualization* (Christ University, Sep 2024): CIA 1 and CIA 2.

## Data
Three course-provided files: loan transactions (primary), branch data and customer data, joined in Tableau with the loan file as the primary table.

## What was built
- Age of applicants in 10-year bins, with maximum and minimum loan amount per bin
- Stacked bar of loan amount by region and marital status (percentage labels)
- Contingency table (region and marital status by lead source) with colour scale
- Treemap of loan amount by branch hierarchy
- Dual-axis quarterly trend of loan amount and interest rate
- **SBI dashboard** with region-wise loan amount, region by risk level, and location by branch type, with region filters
- A four-point **story** (location, branch type, marital status, risk level)
