# Google Analytics 4 on the Demo Store (coursework)

*Digital Transformation*, CIA 1 (Sep 2024). Uses Google's public Merchandise Store demo account, so the data is shared by everyone, not collected by me.
- Tag Manager / GA4 setup steps and a real-time report
- Traffic acquisition comparison, Aug vs Sep 2024 (Direct about 78.9% to about 72%, Organic about 15% to about 17.6%, Cross-network 0% to about 3.4%)
- Revenue by country

## Known limitations
- Uses GA4's built-in charts (the brief asked for Tableau).
- One definition of "Direct" traffic in the write-up is imprecise.
- Recommendations are generic.
