# MySQL Basics: Cricket Roster (coursework)

*Data Management for Business Analytics*, CIA 2 (Sep 2024).
- Database `MyTest11`, table `India11` (11 hand-entered players)
- `CREATE`, `INSERT`, `UPDATE`, `SELECT` with `WHERE`, `ORDER BY`, `LIMIT`, `LIKE`, `DISTINCT`, `COUNT` and `GROUP BY`

## Known limitations
- Small hand-typed data, with no joins, subqueries or window functions.
- `DECIMAL` was declared without precision, so MySQL rounds batting averages to whole numbers.
- The brief's index and query-speed comparison is not included.
